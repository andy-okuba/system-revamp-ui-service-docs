## `GET /{tenantId}/{country}/match/{matchId}`

Returns full match detail including **all** available markets (not just the highlight market). Used on the match/event detail page to render every market group and outcome.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `matchId` | `number` | Yes | Match identifier (same as `match_id` from the highlights endpoint). |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/match/60417210" \
  -H "Accept: application/json"
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `markets` | `Array<Market>` | One entry per market group offered for this match. |
| `markets[].market` | `Array<{ specifier, outcomes, status, status_name }>` | Present for multi-specifier markets (e.g. handicap, over/under lines). When present, `outcomes` at the top level of the market entry may be empty and the real outcomes live inside `market[]`. |
| `markets[].status` / `status_name` | `number` / `string` | Market-level suspension state; `0`/`active` = biddable. |

### Tenant-scoping notes for backend

- The complete market set returned must match the markets **enabled for the tenant** (some tenants may not offer certain exotic markets).
- Odds values must reflect the tenant's own pricing/margin configuration.
