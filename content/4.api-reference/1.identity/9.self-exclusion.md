## `PATCH /{tenantId}/{country}/profile/exclude`

Applies a responsible-gambling self-exclusion window to the authenticated user's account. On success, the frontend immediately logs the user out.

This endpoint is wrapped by the [Proof-of-Work Challenge](/api-reference/identity/proof-of-work-challenge) retry (`endpointName: "profile/exclude"`).

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `Content-Type` | `application/json` | Yes |
| `api-key` | User's auth token | Yes |

### Request body

```json
{
  "profile_id": 55219,
  "reason": "Taking a break",
  "start": "2026-09-23T00:00:00Z",
  "end": "2026-12-23T00:00:00Z"
}
```

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `profile_id` | `number` | Yes | — |
| `reason` | `string` | Yes | User-provided free-text reason. |
| `start` / `end` | `string` (ISO date) | Yes | Exclusion window. |

### Sample request

```bash
curl -X PATCH "https://api.touchvasgaming.com/1001/ke/profile/exclude?lang=en" \
  -H "Content-Type: application/json" \
  -H "api-key: <user-auth-token>" \
  -d '{ "profile_id": 55219, "reason": "Taking a break", "start": "2026-09-23T00:00:00Z", "end": "2026-12-23T00:00:00Z" }'
```

### Sample response

```json
{
  "data": "Your account has been self-excluded until 2026-12-23."
}
```

`HTTP 200` or `HTTP 201` — the frontend logs the user out immediately afterward regardless of response body content.

### Tenant-scoping notes for backend

- This is a compliance-critical, hard-to-reverse action — the exclusion must be enforced tenant-wide for that account and must block login attempts (including [Login](/api-reference/identity/login)) for the excluded window.
