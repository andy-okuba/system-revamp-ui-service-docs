## `GET /{tenantId}/{country}/get/{key}`

Nine different pieces of legal/static content share the **exact same request shape** (query params, headers) and a near-identical response envelope, differing only by the `{key}` path segment and the name of the wrapper array in the response body.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `key` | `string` | Yes | One of the values in the table below. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### `key` values, purpose and response shape

| `key` | Purpose | Response shape |
| --- | --- | --- |
| `license` | Gaming license content | `{ "license_data": [{ "id", "content", "country", "language" }] }` — frontend reads `license_data[0].content`, falling back to top-level `content` if the array is absent. |
| `privacy` | Privacy policy | `{ "privacy_data": [{ "id", "content", "country", "language" }] }` — same fallback pattern. |
| `resgamming` **or** `resgaming` | Responsible gaming policy | `{ "res": "..." }` **or** `{ "resgamming_data": [...] }` / `{ "resgaming_data": [...] }` — see warning below. |
| `tnc` | Terms and conditions | `{ "tnc_data": [{ "id", "content", "country", "language" }] }` — same fallback pattern. |
| `important/info` | Important info banner/page content | `{ "content": "..." }` (flat, no wrapper array). |
| `streaks` | Streaks feature explainer content | `{ "content": "..." }` (flat, no wrapper array). |
| `cnr` | Conflict resolution policy | `{ "content", "country", "id", "language" }` (flat object, no wrapper array). |
| `bonustnc` | Bonus terms and conditions | `{ "content", "country", "id", "language" }` (flat object, no wrapper array). |
| `affiliatestnc` | Affiliate terms and conditions | `{ "content", "country", "id", "language" }` (flat object, no wrapper array). |

::warning
Responsible gaming content uses the `resgaming` path and the `{ "content": "..." }` response shape.
::

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/get/tnc" \
  --data-urlencode "lang=en"
```

### Sample response

```json
{
  "tnc_data": [
    {
      "id": 1,
      "content": "<h2>Terms and Conditions</h2><p>...</p>",
      "country": "ke",
      "language": "en"
    }
  ]
}
```

### Tenant-scoping notes for backend

- All legal/static content is tenant-specific (license numbers, regulatory text, bonus rules differ per operator/jurisdiction).
