## `GET /{tenantId}/{country}/get/banners`

Returns the list of banner images shown in homepage carousels/sliders.

Consumed by `fetchBanners` in `stores/cmsStore.js`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/get/banners" \
  --data-urlencode "lang=en"
```

### Sample response

```json
[
  { "id": 1, "url": "https://cdn.example.com/banners/promo1.jpg", "name": "promo1" },
  { "id": 2, "url": "https://cdn.example.com/banners/promo2.jpg", "name": "promo2" }
]
```

::note
Must be a top-level JSON **array** — the frontend assigns the raw parsed body directly (`banners.value = data ?? []`), with no `data`-wrapper fallback. `404` is treated as "no banners found" (empty state), not a hard error.
::

### Tenant-scoping notes for backend

- Banners are tenant-specific marketing content.
