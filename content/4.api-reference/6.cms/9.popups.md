## `GET /{tenantId}/{country}/get/popups`

Returns a list of in-app promotional popups (e.g. announcement modals shown on load), each with an active window and an optional link.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/get/popups" \
  --data-urlencode "lang=en"
```

### Sample response

```json
[
  {
    "id": 1,
    "image_url": "https://cdn.example.com/popups/weekend-boost.jpg",
    "link": "/boosted",
    "active": 1,
    "start_date": "2026-09-20T00:00:00Z",
    "end_date": "2026-09-27T23:59:59Z",
    "country": "ke",
    "language": "en"
  }
]
```

::note
The frontend accepts either a top-level array **or** `{ "popups": [...] }`. `active` is not filtered client-side by date — confirm whether the backend should only return currently-active popups, or whether the frontend is expected to compare `start_date`/`end_date` itself.
::

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `active` | `0 \| 1` | Whether the popup should currently display. |
| `start_date` / `end_date` | `string` (ISO date) | Active window. |

### Tenant-scoping notes for backend

- Popups are tenant-specific promotional content.
