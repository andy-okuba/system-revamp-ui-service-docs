## `GET /{tenantId}/{country}/get/faq` and `GET /{tenantId}/{country}/get/faq/streaks`

Two near-identical endpoints returning FAQ lists — one general, one specific to the "streaks" feature.

Consumed by `fetchFaqs` and `fetchFaqStreaks` in `stores/cmsStore.js`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/get/faq" \
  --data-urlencode "lang=en"
```

### Sample response

```json
{
  "faq": [
    { "id": 1, "title": "How do I deposit?", "description": "<p>Go to the wallet page and select a payment method.</p>" },
    { "id": 2, "title": "How do I withdraw?", "description": "<p>Withdrawals require a verified payment channel.</p>" }
  ]
}
```

::warning
The frontend accepts **four** possible wrapper keys for the same array — `faq`, `FAQs`, `faqs`, or `data` (checked in that priority order) — for both the general and streaks variants. Standardize on a single key; recommend lowercase `faq`.
::

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `number` | — |
| `title` | `string` | The question. |
| `description` | `string` | The answer, may contain HTML. |

`404` is treated as "no FAQs found" (empty state), not a hard error.

### Tenant-scoping notes for backend

- FAQ content is tenant-specific.
