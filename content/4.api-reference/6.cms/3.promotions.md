## `GET /{tenantId}/{country}/get/promotions`

Returns the list of promotions shown on the promotions page (title, description, CTA link/button text, terms).

::warning
Called by **two independent implementations**:

1. `stores/cmsStore.js` → `fetchPromotions()` — reads `result.Promotions ?? result.promotions ?? []` (accepts either casing)
2. `pages/promotions.vue` → `fetchPromos()` — a **direct, separate fetch** that reads only `res.promotions` (lowercase only), bypassing the store entirely

**Backend team: standardize on a single casing** — recommend lowercase `promotions` since it is the only key the direct page implementation accepts.
::

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/get/promotions" \
  --data-urlencode "lang=en"
```

### Sample response

```json
{
  "promotions": [
    {
      "id": 1,
      "title": "Welcome Bonus",
      "description": "Get a 100% bonus on your first deposit.",
      "url": "https://cdn.example.com/promotions/welcome.jpg",
      "name": "welcome_bonus",
      "link": "/deposit",
      "btn_text": "Deposit Now",
      "terms": "<p>Minimum deposit applies. Full terms apply.</p>",
      "language": "en",
      "country": "ke",
      "status": 1
    }
  ]
}
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `promotions` | `Promotion[]` | `404` is treated as "no promotions found" (empty state), not a hard error. |
| `promotions[].url` | `string` | Promotion image URL. The frontend prefixes with `https://` if the returned value doesn't already start with it — prefer always sending a fully-qualified URL. |
| `promotions[].terms` | `string` | Raw HTML, shown in a modal. |
| `promotions[].status` | `number` | Not currently filtered on client-side — confirm whether inactive (`status: 0`) promotions should be excluded server-side instead. |

### Tenant-scoping notes for backend

- Promotions are tenant-specific marketing content.
