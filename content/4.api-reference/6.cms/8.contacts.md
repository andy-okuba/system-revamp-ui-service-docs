## `GET /{tenantId}/{country}/get/contacts`

Returns support contact details (email, phone, WhatsApp) shown on the contact page.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/get/contacts" \
  --data-urlencode "lang=en"
```

### Sample response

```json
{
  "id": 1,
  "email": "support@example.com",
  "msisdn": "+254700000000",
  "whatsapp": "+254700000000",
  "country": "ke",
  "language": "en"
}
```

::note
Unlike most other CMS endpoints, a non-`2xx` response here is treated as a **hard error** (no silent empty-state fallback), reading `error` or `error_message` from the body.
::

### Tenant-scoping notes for backend

- Support contact details are tenant-specific.
