## `GET /{tenantId}/{country}/jackpot/categories`

Returns the active jackpot categories available for the tenant, optionally filtered by stake type. Used on both the Jackpot and Correct Score category listing pages — same path shape, different host.

### `GET /{tenantId}/{country}/jackpot/categories/all` — Jackpot service only

Same as above but returns **all** categories including inactive ones. No Correct Score equivalent exists in the frontend today.

Consumed by `fetchCategories` (both) and `fetchAllCategories` (Jackpot only) in `stores/jackpotFixtureStore.js` / `stores/correctScoreStore.js`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `stake_type` | `-1 \| 0 \| 1` | `-1` | `-1` = all, `0` = Cash Stake, `1` = M8B (bonus-eligible). |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `api-key` | User's auth token | No — sent if available, but not required. |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/jackpot/categories" \
  --data-urlencode "stake_type=-1" \
  --data-urlencode "lang=en"
```

### Sample response

```json
[
  {
    "id": 12,
    "name": "Mega Jackpot",
    "market_id": 1,
    "specifier": "",
    "minimum_stake": 10,
    "number_of_games": 15,
    "prize": 5000000,
    "stake_type": 0,
    "end": "2026-09-28T18:00:00Z"
  }
]
```

::note
Must be a top-level JSON **array** — a non-array response is treated as a hard failure ("Failed to load jackpot categories"), not an empty state.
::

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `number` | Used as `categoryId` on [Jackpots by Category](/api-reference/jackpot-correct-score/jackpots-by-category) and [Results](/api-reference/jackpot-correct-score/jackpot-results). |
| `market_id` / `specifier` | `number` / `string` | The single market all fixtures in this category's jackpots are picked on. |
| `stake_type` | `number` | `0` cash, `1` bonus-eligible (M8B). |

### Tenant-scoping notes for backend

- Categories, prize pools and stake types are tenant-specific jackpot product configuration.
