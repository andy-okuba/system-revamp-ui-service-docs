## `POST /{tenantId}/{country}/jackpot/{jackpotId}/bet/{betId}`

Updates the scoreline picks of an unsettled Correct Score bet. Jackpot bets cannot be edited after placement.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `jackpotId` | `number` | Yes | The jackpot `id` the bet belongs to. |
| `betId` | `number` | Yes | The existing bet's `id`, from [Bet History](/api-reference/jackpot-correct-score/bet-history). |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `Content-Type` | `application/json` | Yes |
| `api-key` | User's auth token | Yes |

### Request body

Same shape as the Correct Score [Place Bet](/api-reference/jackpot-correct-score/place-bet) payload — the full, updated set of scoreline picks is resubmitted (not a partial patch).

```json
{
  "bet_type": 1,
  "bets": [
    { "match_id": 60417210, "home_score": 1, "away_score": 1 }
  ],
  "booking_code": "",
  "campaign": "null",
  "country_code": "ke",
  "ip_address": "",
  "lang": "en",
  "medium": "null",
  "source": 1,
  "stake": 50,
  "stake_type": "cash",
  "utm_source": "null"
}
```

### Sample response

Same shape as [Place Bet](/api-reference/jackpot-correct-score/place-bet):

```json
{
  "bet_id": "CS-2026-000123456",
  "data": "Bet Updated Successfully",
  "status": 201
}
```

Both `HTTP 200` and `HTTP 201` are accepted as success here (unlike Place Bet, which only accepts `201`).

### Tenant-scoping notes for backend

- Must only allow updating bets owned by the authenticated user, within the requesting tenant, and only while still unsettled/editable.
