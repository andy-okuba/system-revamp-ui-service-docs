## `GET /{tenantId}/{country}/jackpot/{categoryId}`

Returns the open jackpot(s) for a category, each with its full list of fixtures and pickable outcomes.

::warning
**The response shape differs between the two services** — do not assume a shared contract just because the path is identical:

- **Jackpot**: each fixture has `outcomes: Outcome[]` where each outcome carries its own `market_id`/`specifier`/`status` (since different fixtures in the same jackpot can use different markets).
- **Correct Score**: each fixture instead has a `picked: string` field (the currently-picked scoreline, if any) and `outcomes: BaseJackpotOutcome[]` without `market_id`/`specifier`/`status` (the market is fixed — exact score — so it isn't repeated per outcome).
::

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `categoryId` | `number` | Yes | The category `id` from [Categories](/api-reference/jackpot-correct-score/categories). |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `country` | `string` | `ke` | Lowercase country code represented by the `{country}` path segment. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `api-key` | User's auth token | No — sent if available. |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/jackpot/12" \
  -H "Accept: application/json"
```

### Tenant-scoping notes for backend

- Jackpot contents, prize pools and fixtures are tenant-specific.
