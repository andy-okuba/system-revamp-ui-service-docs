## `GET /{tenantId}/{country}/jackpot/{categoryId}/results`

Returns settled/historical jackpots for a category, with per-fixture results and win/loss counts.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `categoryId` | `number` | Yes | The category `id` from [Categories](/api-reference/jackpot-correct-score/categories). |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `page` | `number` | `1` | 1-indexed page number. |
| `per_page` | `number` | `10` | Page size. |
| `sort` | `string` | `jackpot.id\|desc` | Sort field and direction, pipe-separated. |
| `start` / `end` | `string` (ISO date) | — | Optional date range filter. |
| `country_code` | `string` | `KE` (uppercased) | **Jackpot service only** — sent uppercased. **Not sent at all** by the Correct Score service for this endpoint. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `api-key` | User's auth token | No — sent if available. |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/jackpot/12/results" \
  --data-urlencode "page=1" \
  --data-urlencode "per_page=10" \
  --data-urlencode "sort=jackpot.id|desc"
```

::warning
`data: null` in the raw response is normalized to an empty array (`[]`) client-side for both services — but note the Correct Score variant **only** unwraps `{ "data": [...] }`, while the Jackpot variant unwraps `{ "data": [...] }` **or** accepts a bare top-level array. Recommend standardizing on a bare top-level array for both, consistent with [Jackpots by Category](/api-reference/jackpot-correct-score/jackpots-by-category).
::
