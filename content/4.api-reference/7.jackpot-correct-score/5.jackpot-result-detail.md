## `GET /{tenantId}/{country}/jackpot/{jackpotId}/result`

Returns the settled result detail for a single Correct Score jackpot (not category-scoped — a single jackpot instance). No Jackpot-service equivalent exists in the frontend today; single-jackpot detail there is derived client-side from the category-level [Jackpot Results](/api-reference/jackpot-correct-score/jackpot-results) list instead.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `jackpotId` | `number` | Yes | The jackpot `id` (not the category id). |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `api-key` | User's auth token | No — sent if available. |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/jackpot/598/result" \
  -H "Accept: application/json"
```

### Sample response

Same per-jackpot row shape as one item from [Jackpot Results](/api-reference/jackpot-correct-score/jackpot-results) (Correct Score variant), returned as a single object rather than an array:

```json
{
  "id": 598,
  "jackpot_category_id": 12,
  "jackpot_name": "Correct Score Jackpot #598",
  "prize": 1000000,
  "stake": 50,
  "status": 2,
  "fixture": [
    {
      "match_id": 60415000,
      "match_number": 1,
      "home": "Arsenal",
      "away": "Chelsea",
      "results": {
        "home_score": "2",
        "away_score": "1",
        "picked": { "home_score": "1", "away_score": "0", "won": 0 }
      }
    }
  ]
}
```

### Tenant-scoping notes for backend

- Must only resolve a `jackpotId` belonging to the requesting tenant.
