## `GET /{tenantId}/{country}/profile/channels/resend/{id}`

Resends the OTP for a payment channel account pending verification.

### `POST /{tenantId}/{country}/profile/channels/verify/{id}`

Confirms the OTP to complete verification of a payment channel account, making it eligible for withdrawals.

Both consumed in `stores/walletStore.js` (`resendChannelOtp`, `verifyChannel`).

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `id` | `number` | Yes | The payment account `id` (from [Payment Channels](/api-reference/wallet/payment-channels) `accounts[].id`) to resend/verify. |

### Query parameters (verify only)

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. Sent on `verify`; **not** sent on `resend`. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `Content-Type` | `application/json` | Yes |
| `api-key` | User's auth token | Yes |

### Verify request body

```json
{ "otp": 482913 }
```

| Field | Type | Notes |
| --- | --- | --- |
| `otp` | `number` | The one-time code sent to the user, submitted as a **number**. |

### Sample requests

```bash
curl "https://api.touchvasgaming.com/1001/ke/profile/channels/resend/9001" \
  -H "api-key: <user-auth-token>"
```

```bash
curl -X POST "https://api.touchvasgaming.com/1001/ke/profile/channels/verify/9001?lang=en" \
  -H "Content-Type: application/json" \
  -H "api-key: <user-auth-token>" \
  -d '{ "otp": 482913 }'
```

### Status codes recognized by the frontend

| Endpoint | Status | Meaning |
| --- | --- | --- |
| `resend` | `200` | OTP resent successfully. |
| `resend` | `404` | Channel/account not found. |
| `verify` | `201` | Verified successfully; frontend re-fetches the channel list. |
| `verify` | `422` | Invalid OTP. |
| both | `401` | Session expired. |

### Tenant-scoping notes for backend

- Must only allow resend/verify for accounts owned by the authenticated user within the requesting tenant.
