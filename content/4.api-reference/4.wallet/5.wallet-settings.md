## `GET /{tenantId}/{country}/get/settings`

Returns deposit and withdrawal amount/frequency limits used to validate user input before submitting a deposit or withdrawal request.

Consumed by `fetchWalletSettings` in `stores/walletStore.js`. Cached client-side for 5 minutes.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `Content-Type` | `application/json` | Yes |
| `api-key` | User's auth token | Yes |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/get/settings" \
  --data-urlencode "lang=en" \
  -H "api-key: <user-auth-token>"
```

### Sample response

```json
{
  "deposit_minimum_amount": 5,
  "deposit_maximum_amount": 20000,
  "deposit_daily_limit": 100000,
  "withdrawal_minimum_amount": 50,
  "withdrawal_maximum_amount": 50000,
  "withdrawal_daily_limit": 100000,
  "withdrawal_daily_counts_limit": 3
}
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `deposit_minimum_amount` / `deposit_maximum_amount` | `number` | Allowed range for a single deposit. |
| `deposit_daily_limit` | `number` | Cumulative deposit cap per day. |
| `withdrawal_minimum_amount` / `withdrawal_maximum_amount` | `number` | Allowed range for a single withdrawal. |
| `withdrawal_daily_limit` | `number` | Cumulative withdrawal cap per day. |
| `withdrawal_daily_counts_limit` | `number` | Maximum number of withdrawal **requests** allowed per day, independent of amount. |

::warning
`pages/transaction.vue`'s legacy deposit flow hardcodes its own limits (`5`–`20000`) directly in the frontend instead of reading them from this endpoint — flagging as a maintenance risk, not a payload issue: if backend changes these limits, that page will not reflect it.
::

### Tenant-scoping notes for backend

- Deposit/withdrawal limits are tenant-specific (regulatory and risk-based configuration).
