## `POST /{tenantId}/{country}/deposit/status`

Polls the status of a previously initiated deposit (see [Deposit](/api-reference/wallet/deposit)), typically used while waiting for a mobile money confirmation prompt to be actioned by the user.

Consumed by `checkDepositStatus` in `stores/walletStore.js`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `Content-Type` | `application/json` | Yes |
| `api-key` | User's auth token | Yes |

### Request body

```json
{
  "payment_channel_id": 3,
  "reference": "DEP-2026-000123456"
}
```

| Field | Type | Notes |
| --- | --- | --- |
| `payment_channel_id` | `number` | The channel used for the original deposit request. |
| `reference` | `string` | The reference returned by (or associated with) the [Deposit](/api-reference/wallet/deposit) call. |

### Sample request

```bash
curl -X POST "https://api.touchvasgaming.com/1001/ke/deposit/status?lang=en" \
  -H "Content-Type: application/json" \
  -H "api-key: <user-auth-token>" \
  -d '{ "payment_channel_id": 3, "reference": "DEP-2026-000123456" }'
```

### Sample response

```json
{
  "status": "completed",
  "reference": "DEP-2026-000123456",
  "amount": 500,
  "message": "Deposit completed successfully"
}
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `status` | `string` | e.g. `"pending"`, `"completed"`, `"failed"` — confirm the full enum with backend. |
| `amount` | `number` | Present once the deposit is confirmed. |
| `message` | `string` | Human-readable status message. |

On success (`HTTP 200`), the frontend re-fetches [Balance](/api-reference/wallet/balance).

### Tenant-scoping notes for backend

- Must only resolve a `reference` that belongs to a deposit initiated by the authenticated user under the requesting tenant.
