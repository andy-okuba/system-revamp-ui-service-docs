## `GET /{tenantId}/{country}/balance`

Returns the authenticated user's main (`b1`) and bonus (`b2`) wallet balances. Cached client-side for 30 seconds unless a force-refresh is requested (e.g. immediately after a deposit/withdrawal).

Consumed by `fetchBalance` in `stores/walletStore.js` (bundled `wallet-ui-service` package).

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `Content-Type` | `application/json` | Yes |
| `api-key` | User's auth token | Yes |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/balance" \
  --data-urlencode "lang=en" \
  -H "api-key: <user-auth-token>"
```

### Sample response

```json
{
  "b1": 1250.5,
  "b2": 75
}
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `b1` | `number` | Main (cash) wallet balance. Frontend calls this `mainBalance`. |
| `b2` | `number` | Bonus wallet balance. Frontend calls this `walletBonusBalance`. `mainBalance + walletBonusBalance` is displayed as `totalBalance`. |

::warning
`b1`/`b2` are opaque, non-descriptive field names carried over from the current backend — consider renaming to `main_balance`/`bonus_balance` in a future version, but any rename must be coordinated with a frontend change.
::

### Tenant-scoping notes for backend

- Balances must be looked up for the authenticated user **within the requesting tenant** — a user id must not resolve to a balance under a different tenant.
