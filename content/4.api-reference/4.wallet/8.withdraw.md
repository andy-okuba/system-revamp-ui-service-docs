## `POST /{tenantId}/{country}/withdraw`

Withdraws funds from the user's main wallet balance to a verified payment channel/account.

Consumed by `withdraw` in `stores/walletStore.js`, used by `pages/withdrawal.vue`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `Content-Type` | `application/json` | Yes |
| `api-key` | User's auth token | Yes |

### Request body

```json
{
  "amount": 200,
  "account_id": 2000000019,
  "account_number": "2547XXXXXXXX",
  "account_type": 1,
  "payment_channel_id": 3
}
```

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `amount` | `number` | Yes | Withdrawal amount, validated client-side against [Wallet Settings](/api-reference/wallet/wallet-settings). |
| `account_id` | `number` | Yes | Operator/merchant account identifier. |
| `account_number` | `string` | Yes | The destination account for the selected channel. |
| `account_type` | `number` | Yes | Numeric account type code (channel-specific). |
| `payment_channel_id` | `number` | Yes | The channel `id` from [Payment Channels](/api-reference/wallet/payment-channels) — must already be verified. |

### Sample request

```bash
curl -X POST "https://api.touchvasgaming.com/1001/ke/withdraw?lang=en" \
  -H "Content-Type: application/json" \
  -H "api-key: <user-auth-token>" \
  -d '{
    "amount": 200,
    "account_id": 2000000019,
    "account_number": "2547XXXXXXXX",
    "account_type": 1,
    "payment_channel_id": 3
  }'
```

### Sample response

```json
{
  "data": "success"
}
```

::note
Success is recognized by the frontend as **either** `HTTP 201` **or** a response body where `data === "success"` — this dual success condition should be simplified to a single, unambiguous signal (e.g. always `HTTP 201` with a structured body).
::

On success, the frontend re-fetches [Balance](/api-reference/wallet/balance).

### Tenant-scoping notes for backend

- Withdrawal limits, allowed channels and account verification must be enforced per-tenant.
- This is a money-moving, hard-to-reverse operation — ensure idempotency and fraud checks before releasing funds.
