## `GET /{tenantId}/{country}/bookings/{bookingCode}`

Resolves a generated or shared booking code into the list of selections it represents, so they can be loaded into the user's bet slip.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `bookingCode` | `string` | Yes | The booking code to resolve (e.g. returned as `bet_id`/`booking_code` from other endpoints). |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/bookings/BOOST-8821" \
  --data-urlencode "lang=en"
```

### Sample response

```json
[
  {
    "match_id": 60417210,
    "game_id": 1,
    "market_id": 1,
    "market_name": "1X2",
    "outcome_id": "1",
    "outcome_name": "Home",
    "odds": 2.1,
    "event": "Arsenal vs Chelsea",
    "date": "2026-09-27T15:00:00Z",
    "producer_id": 1,
    "status": 0,
    "status_name": "active",
    "active": 1,
    "specifier": "",
    "sport_id": 1,
    "tournament_id": 17,
    "tournament": "Premier League"
  }
]
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| (top-level) | `Selection[]` | Must be a top-level JSON **array**; an empty array or non-array response is treated as "booking code not found / has no selections". |
| `event` | `string` | Match name, parsed client-side by splitting on `" vs "`, `" v "` (case-insensitive) to derive home/away team names — prefer sending this as `"Home vs Away"`. |
| `active` | `0 \| 1` | Mapped by the frontend to a `market_status` of `0` (active) or `1` (suspended). |

### Tenant-scoping notes for backend

- A booking code created under one tenant must not resolve when queried through a different tenant's `tenantId`.
