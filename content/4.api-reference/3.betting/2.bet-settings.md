## `GET /{tenantId}/{country}/get/settings`

Returns the current betting rules (stake limits, minimum odds, maximum combined odds/winnings, withholding tax) used to validate a bet client-side before it is submitted.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/get/settings" \
  --data-urlencode "lang=en"
```

### Sample response

```json
{
  "minimum_stake": 10,
  "maximum_stake": 100000,
  "minimum_single_bet_odds": 1.1,
  "minimum_multibet_odds": 1.2,
  "max_total_odds": 5000,
  "max_winning": 1000000,
  "with_holding_tax": 0.2
}
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `minimum_stake` / `maximum_stake` | `number` | Allowed stake range for a single bet slip. |
| `minimum_single_bet_odds` | `number` | Minimum odds allowed for a single (non-combo) bet. |
| `minimum_multibet_odds` | `number` | Minimum odds allowed per selection in a multibet. |
| `max_total_odds` | `number` | Maximum allowed combined odds for a bet slip. |
| `max_winning` | `number` | Maximum possible payout allowed for a single bet. |
| `with_holding_tax` | `number` | Tax rate applied to winnings (decimal fraction, e.g. `0.2` = 20%). |

::warning
The frontend assigns the raw response body directly to its settings state — every field above must always be present with the correct type, since there are no client-side defaults/fallbacks for this endpoint.
::

### Tenant-scoping notes for backend

- These limits must reflect the tenant's own regulatory/business configuration (tax rate in particular is jurisdiction- and operator-specific).
