## `PATCH /{tenantId}/{country}/password/reset`

Resets the account password using the OTP obtained via [Forgot Password](/api-reference/identity/forgot-password), and establishes a session on success.

Consumed by `resetPassword` in `stores/authStore.js`. Wrapped by the [Proof-of-Work Challenge](/api-reference/identity/proof-of-work-challenge) retry (`endpointName: "password/reset"`).

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

### Request body

```json
{
  "country_code": "ke",
  "msisdn": 254712345678,
  "code": 4821,
  "password": "NewHunter3"
}
```

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `country_code`, `msisdn`, `code` | — | Yes | Same as [Verify OTP](/api-reference/identity/verify-otp), identifying the reset request. |
| `password` | `string` | Yes | The new password. |
| `finger_print`, `email`, `username` | — | No | Present in the shared type, not currently populated by this flow. |

### Sample request

```bash
curl -X PATCH "https://api.touchvasgaming.com/1001/ke/password/reset?lang=en" \
  -H "Content-Type: application/json" \
  -d '{ "country_code": "ke", "msisdn": 254712345678, "code": 4821, "password": "NewHunter3" }'
```

### Sample response

Same `Identity` shape as [Login](/api-reference/identity/login), wrapped with an optional message:

```json
{
  "id": 55219,
  "msisdn": "254712345678",
  "first_name": "Jane",
  "last_name": "Kamau",
  "referral_code": "JANE55219",
  "status": 1,
  "auth": "eyJhbGciOiJIUzI1NiIs...",
  "data": "Password reset successfully."
}
```

`HTTP 200` or `HTTP 201` establish the session directly — the user is logged in immediately after a successful reset, without a separate login step.

### Tenant-scoping notes for backend

- Same tenant-scoping requirements as [Verify OTP](/api-reference/identity/verify-otp).
