## `GET /{tenantId}/{country}/winboost`

Returns the WinBoost configuration: a tiered percentage payout boost applied to multibets, based on number of selections, subject to minimum odds/stake and excluded markets.

::warning
The endpoint uses the mandatory `/{tenantId}/{country}/` path prefix. The `lang` query parameter is optional and defaults to `en` when omitted.
::

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. Only sent by the `bettingStore` consumer. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/winboost" \
  --data-urlencode "lang=en"
```

### Sample response

```json
{
  "status": 1,
  "minimum_odds": 1.2,
  "minimum_stake": 10,
  "maximum_winning": 1000000,
  "excluded_market_ids": "11",
  "boost": [
    { "number_of_outcome": 3, "percentage": 5 },
    { "number_of_outcome": 5, "percentage": 10 },
    { "number_of_outcome": 10, "percentage": 25 }
  ]
}
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `status` | `0 \| 1` | `0` disables WinBoost entirely for the tenant. |
| `minimum_odds` | `number` | Minimum **total** bet-slip odds required to qualify. |
| `minimum_stake` | `number` | Minimum stake required to qualify. |
| `maximum_winning` | `number` | Payout is capped at this value even after the boost is applied. |
| `excluded_market_ids` | `string` | Comma-separated market IDs (e.g. `"11,18"`) that disqualify a bet slip if present among the picks. |
| `boost` | `Array<{ number_of_outcome, percentage }>` | Tiers keyed by number of selections; the frontend applies the **highest tier the pick count meets or exceeds**. |

### Tenant-scoping notes for backend

- Boost tiers, thresholds and excluded markets are all tenant-specific promotional configuration.
