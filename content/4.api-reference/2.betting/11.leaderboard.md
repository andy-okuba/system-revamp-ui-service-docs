## `GET /{tenantId}/{country}/leaderboard`

Returns the current weekly sportsbook leaderboard (ranked bettors) along with the leaderboard's configuration and the authenticated user's own position, even if outside the returned `entries` page.

Consumed by `fetchLeaderboard` in `bettingStore.js`.

::warning
The current frontend implementation calls this endpoint with **no country parameter at all** (`fetchLeaderboard(token, currency, lang)` has no country argument). Under the mandatory `/{tenantId}/{country}/` standard, this must be updated to include the country path segment.
::

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |
| `currency` | `string` | `kes` | Currency code used to display monetary values. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `Content-Type` | `application/json` | Yes |
| `api-key` | User's auth token | Yes — the frontend refuses to call this endpoint without a token. |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/leaderboard" \
  --data-urlencode "lang=en" \
  --data-urlencode "currency=kes" \
  -H "api-key: <user-auth-token>"
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `entries` | `LeaderboardEntry[]` | Ranked list, limited by `settings.leaderboard_limit`. |
| `settings` | `LeaderboardSettings` | Leaderboard configuration (ranking metric, qualification rules, active week window). |
| `user_position` | `LeaderboardEntry \| null` | The authenticated user's own row, even if outside the top `entries` — `null` if the user has no qualifying activity this week. |
| `settings.metric` | `string` | The field `entries` are ranked/sorted by (e.g. `"profit"`). |
| `settings.voided_bet_behaviour` | `string` | How voided bets affect ranking, e.g. `"exclude"`. |

### Tenant-scoping notes for backend

- The leaderboard, its ranking rules and the active week window are all tenant-specific — never merge bettors across tenants into one ranking.
