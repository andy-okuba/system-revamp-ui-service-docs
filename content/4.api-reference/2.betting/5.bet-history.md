## `GET /{tenantId}/{country}/bet`

Returns a paginated list of the authenticated user's placed bets, filterable by status, stake type and date range. Same base path as [Place Bet](/api-reference/betting/place-bet) — differentiated by HTTP method.

Responses are cached client-side for 30 seconds per unique query+token combination.
### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |
| `page` | `number` | `1` | 1-indexed page number. |
| `per_page` | `number` | `10` | Page size. |
| `status` | `number` | — | Bet status filter: `-1` cancelled, `0` pending, `1` lost, `2` won, `3` voided, `5` cashed out. |
| `stake_type` | `number` | `1` | `1` cash, `2` bonus, `3` freebet. |
| `start` | `string` (date) | — | Start of date range filter. |
| `end` | `string` (date) | — | End of date range filter. |
| `sort` | `string` | `bet.created\|desc` | Sort field and direction, pipe-separated. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `api-key` | User's auth token | Yes |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/bet" \
  --data-urlencode "lang=en" \
  --data-urlencode "page=1" \
  --data-urlencode "per_page=10" \
  --data-urlencode "stake_type=1" \
  --data-urlencode "sort=bet.created|desc" \
  -H "api-key: <user-auth-token>"
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `current_page`, `per_page`, `total` | `number` | Used to compute total pages client-side (`ceil(total / per_page)`). |
| `data` | `BetHistoryItem[]` | One entry per placed bet slip. |
| `data[].bets` | `number` | **Count** of selections in the slip (not an array). |
| `data[].status` | `number` | Same enum as the `status` query filter. |
| `data[].won` | `number` | `-2` cancelled, `-1` pending, `0` lost, `1` won, `2` voided, `5` cashed out. |
| `data[].cashout_value` | `number` | Present only when cashout is currently available for this bet. |
| `data[].picked` | `Array<Picked>` | One entry per selection; `picked[].won` uses the same enum as `data[].won`, evaluated per-selection. |

::warning
`bets` (a count) and `picked` (the actual selection array) are distinct fields in this contract.
::

### Tenant-scoping notes for backend

- Must only return bets placed by the authenticated user **within the requesting tenant**; a user id must not be resolvable across tenants.
