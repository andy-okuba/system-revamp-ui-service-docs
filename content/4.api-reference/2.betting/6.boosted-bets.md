## `GET /{tenantId}/{country}/bet/boost`

Returns a curated list of pre-built, boosted-odds bet slips (each bundling several selections under one shareable booking code) shown in the homepage/promotions carousel.

::warning
The current frontend implementation calls this endpoint with **no path or query parameters for country at all** (`${bettingUrl}/bet/boost`). Under the mandatory `/{tenantId}/{country}/` standard, this composable must be updated to include both segments.
::

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/bet/boost" \
  -H "Accept: application/json"
```

::note
The frontend accepts either a top-level array **or** an object of the shape `{ "data": [...] }` — both are supported, but a bare array is the preferred/primary shape.
::

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| (array item) `booking_code` | `string` | Lets the user load this exact slip via [Booking Code](/api-reference/betting/booking-code). |
| (array item) `percentage_boost` | `number` | Extra payout percentage applied to this specific curated slip. |
| (array item) `priority` | `number` | Display ordering; lower/higher-first convention should match the Fixture / Sports `boosted_priority` convention. |
| (array item) `markets` | `Array<BoostedMarket>` | The individual selections that make up the boosted slip. |

### Tenant-scoping notes for backend

- Boosted slips are tenant-specific marketing content — never share the same curated list across tenants.
