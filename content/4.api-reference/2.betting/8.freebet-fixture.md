## `GET /{tenantId}/{country}/freebet/fixture`

Returns the single fixture currently configured as eligible for the platform's freebet promotion, along with its 1X2 market, so the frontend can render a "bet on this game for free" prompt.

Consumed by `fetchFreebetFixture` in `bettingStore.js`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/freebet/fixture" \
  --data-urlencode "lang=en"
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `data` | `Array<Fixture>` | Only the **first** element is used; return the single active freebet fixture as `data[0]`. An empty/non-array `data` is treated as "freebet not currently available". |
| `data[].market_status` | `number` | `0` = active. |
| `data[].producer_id` | `number` | Defaults to `3` (live) client-side if omitted — prefer always sending it explicitly. |

### Tenant-scoping notes for backend

- The eligible freebet fixture is a tenant-specific promotional configuration, not a shared global value.
