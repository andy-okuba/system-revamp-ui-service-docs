## `GET /{tenantId}/{country}/tournament/{tournamentId}`

Returns the leaderboard/results for a tournament — every qualifying participant, their stake/bet activity and ranking.

Consumed by `fetchResults` in `pages/tournaments/[id].vue`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `tournamentId` | `string` | Yes | The tournament `id` from [Tournaments](/api-reference/casino/tournaments). |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/tournament/501" \
  -H "Accept: application/json"
```

### Sample response

```json
[
  {
    "id": 9001,
    "first_name": "John",
    "msisdn": "2547XXXXXXXX",
    "bets": "24",
    "stake": "1200",
    "position": { "number": "1", "points": "980.50" }
  },
  {
    "id": 9002,
    "first_name": "Jane",
    "msisdn": "2547YYYYYYYY",
    "bets": "18",
    "stake": "900",
    "position": { "number": "2", "points": "845.00" }
  }
]
```

::note
Must be a top-level JSON **array**; an empty array or `null` renders a "Leaderboard data not available" empty state.
::

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| (array item) `id` | `number` | Row key. |
| (array item) `first_name` | `string` | Displayed name; falls back to `"N/A"` if absent. |
| (array item) `msisdn` | `string` | Phone number, displayed as-is — confirm masking/privacy requirements with the backend/compliance team before exposing this publicly. |
| (array item) `bets` | `string` | Number of qualifying bets, sent as a **string**. |
| (array item) `stake` | `string` | Total qualifying stake, sent as a **string**. |
| (array item) `position.number` | `string` | Rank, sent as a **string**. |
| (array item) `position.points` | `string` | Tournament points, sent as a **string**, parsed with `parseFloat(...).toFixed(2)` client-side. |

::warning
`bets`, `stake`, `position.number` and `position.points` are all consumed as **strings**, not numbers — keep this type consistent with [Tournament Position](/api-reference/casino/tournament-position), which returns the same `position` shape for the authenticated user.
::

### Tenant-scoping notes for backend

- Confirm whether `msisdn` should be masked/redacted for a public leaderboard endpoint before implementation — this is a compliance question worth raising with the backend team, not purely a payload-shape one.
