## `GET /{tenantId}/{country}/category`

Returns the list of casino game categories (e.g. Slots, Live Casino, Table Games) used to filter the game catalogue and to render highlighted category rails.

Consumed by `fetchCategories` in `stores/casinoStore.js` (bundled `casino-ui-service` package).

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/category" \
  --data-urlencode "lang=en" \
  -H "Accept: application/json"
```

### Sample response

```json
[
  { "id": 1, "name": "Slots", "short_name": "slots", "priority": 10, "status": 1, "highlights": 1 },
  { "id": 2, "name": "Live Casino", "short_name": "live", "priority": 9, "status": 1, "highlights": 1 },
  { "id": 3, "name": "Table Games", "short_name": "table", "priority": 5, "status": 1, "highlights": 0 }
]
```

::note
The frontend accepts either a top-level array **or** an object of the shape `{ "data": [...] }` — both are supported, but a bare array is the preferred/primary shape. It also recognizes an error body `{ "error_code": ..., "error_message": "..." }` and surfaces `error_message` instead of the category list.
::

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| (array item) `id` | `number` | Used as `category_id` filter on [Games](/api-reference/casino/games) and [Popular Games](/api-reference/casino/popular-games). |
| (array item) `short_name` | `string` | Used to match games via `game.category_short_name`. |
| (array item) `priority` | `number` | Categories are sorted **descending** by this value client-side. |
| (array item) `status` | `0 \| 1` | Only `status: 1` categories are considered "active" and shown. |
| (array item) `highlights` | `0 \| 1` | `1` marks the category for a dedicated homepage/highlight rail. |

### Tenant-scoping notes for backend

- Categories (including which ones are `highlights`) are tenant-specific catalogue configuration.
