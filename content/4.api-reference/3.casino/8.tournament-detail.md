## `GET /{tenantId}/{country}/get/tournament/{tournamentId}`

Returns full detail for a single tournament: prize breakdown, the games that count towards it, and its terms and conditions.

Consumed by `fetchTournament` in `pages/tournaments/[id].vue`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `tournamentId` | `string` | Yes | The tournament `id` from [Tournaments](/api-reference/casino/tournaments). |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/get/tournament/501" \
  -H "Accept: application/json"
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `term_and_conditions` | `string` | Raw HTML, rendered as-is via `v-html` — sanitize server-side before returning. |
| `prizes` | `TournamentPrize[]` | Prize breakdown by finishing `position`; frontend sums `reward` client-side to display the total prize pool. |
| `games` | `TournamentGame[] \| null` | `null` (not `[]`) is treated as "no tournament games available" and renders an empty state — send `null` explicitly rather than an empty array if intentional, otherwise send `[]`. |

### Tenant-scoping notes for backend

- Prize pools, qualifying games and terms are tenant-specific; validate `tournamentId` belongs to the requesting tenant before returning detail.
