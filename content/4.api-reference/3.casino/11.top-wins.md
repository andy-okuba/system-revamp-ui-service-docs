## `GET /{tenantId}/{country}/games/winnings`

Returns a list of recent notable casino wins, used to populate the scrolling "Top Wins" ticker on the casino lobby.

Consumed by `fetchWinnings` in `components/casino/TopWins.vue`. Not called at all if the component is given a `wins` prop directly by its parent.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/games/winnings" \
  -H "Accept: application/json"
```

### Sample response

```json
[
  {
    "provider_id": 12,
    "game_name": "Sweet Bonanza",
    "game_id": "vs20fruitsw",
    "image": "https://cdn.example.com/games/sweet-bonanza.jpg",
    "user_name": "J*** K.",
    "amount": 245000,
    "currency": "KES"
  }
]
```

::note
Must be a top-level JSON **array**; any non-array response is treated as "no wins to display" and the ticker section is hidden entirely.
::

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| (array item) `user_name` | `string` | Should already be masked/anonymized server-side (e.g. `"J*** K."`) — the frontend displays it verbatim. |
| (array item) `amount` | `number` | Win amount in the given `currency`. |
| (array item) `game_id` / `game_name` | `string` | Used to build a "play this game" deep link. |

### Tenant-scoping notes for backend

- Wins shown must come from **the requesting tenant's own** player activity — never surface another tenant's wins.
