## `GET /{tenantId}/{country}/games`

Returns a paginated list of casino games, filterable by category, provider, jackpot status and free-text name search. This is the primary endpoint behind the casino lobby grid.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |
| `page` | `number` | `1` | 1-indexed page number. |
| `per_page` | `number` | `100` | Page size. |
| `category_id` | `number` | — | Filter by category id from [Categories](/api-reference/casino/categories). |
| `provider_id` | `number` | — | Filter by provider id from [Providers](/api-reference/casino/providers). |
| `jackpot` | `number` | — | Filter to games belonging to a specific jackpot id. |
| `name` | `string` | — | Free-text search over game name. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/games" \
  --data-urlencode "lang=en" \
  --data-urlencode "page=1" \
  --data-urlencode "per_page=100" \
  --data-urlencode "category_id=1"
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `total`, `per_page`, `current_page`, `last_page`, `from`, `to` | `number` | Standard pagination envelope. |
| `data` | `CasinoGame[]` | One entry per game. |
| `data[].demo` | `0 \| 1` | `1` = demo/free-play mode is available for this game. |
| `data[].jackpot_data` | `object` | `status: 1` and `amount > 0` marks the game as a live jackpot game (used to build the "jackpot games" rail). |

::warning
When loading more results (infinite scroll), the frontend de-duplicates games by `id` and stops paginating once a page returns no new unique ids — ensure `id` is stable and unique per game across pages.
::

### Tenant-scoping notes for backend

- The game catalogue, availability (`status`), demo mode and jackpot linkage are all tenant-specific (provider integrations differ per operator).
