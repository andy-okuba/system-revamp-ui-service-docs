## `GET /{tenantId}/{country}/tournaments`

Returns the list of casino tournaments (used on the tournaments listing page and the homepage tournament carousel).

Consumed by `fetchTournaments` in `stores/casinoStore.js`, and independently by `components/casino-tournament.vue`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. Sent by `stores/casinoStore.js`; **not** sent by `components/casino-tournament.vue`. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/tournaments" \
  --data-urlencode "lang=en"
```

### Sample response

```json
[
  {
    "id": 501,
    "name": "Weekend Slots Battle",
    "image": "https://cdn.example.com/tournaments/weekend-slots.jpg",
    "country_code": "ke",
    "created": "2026-09-01T00:00:00Z",
    "start_time": "2026-09-20T00:00:00Z",
    "end_time": "2026-09-27T23:59:59Z",
    "status": 1,
    "minimum_stake": 10,
    "qualifying_points": 100
  }
]
```

::note
Must be a top-level JSON **array**; the frontend assigns the raw parsed body directly with no `data`-wrapper fallback for this endpoint (unlike Games/Categories/Providers).
::

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `number` | Used to link to [Tournament Detail](/api-reference/casino/tournament-detail), [Tournament Results](/api-reference/casino/tournament-results) and [Position](/api-reference/casino/tournament-position). |
| `status` | `number` | Tournament state (e.g. active/upcoming/ended) — exact enum not yet consumed by the frontend beyond display; confirm values with backend. |
| `minimum_stake` | `number` | Minimum stake per qualifying bet to earn tournament points. |
| `qualifying_points` | `number` | Points threshold referenced by tournament rules/prizing. |

### Tenant-scoping notes for backend

- Tournaments, their prize pools and qualification rules are tenant-specific promotions.
