## `GET /{tenantId}/{country}/providers`

Returns the list of casino game providers (e.g. Pragmatic Play, Evolution) used to populate the provider filter panel.

Consumed directly in `pages/casino.vue` via `fetchProviders()` — **not** through the `casino-ui-service` package's store.

::warning
The bundled `casino-ui-service` package defines a `providers` endpoint internally (`/providers?lang=...&country_code=...`) but **no method in the package ever calls it** — it is dead code. The actual, live call from `pages/casino.vue` hits `/providers` with **no query parameters at all**. Standardize on the mandatory `/{tenantId}/{country}/providers` path with no additional query parameters required, unless the backend team has a reason to keep `lang` supported.
::

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/providers" \
  -H "Accept: application/json"
```

### Sample response

```json
[
  { "id": 12, "name": "Pragmatic Play", "status": 1 },
  { "id": 20, "name": "Evolution", "status": 1 },
  { "id": 30, "name": "Ezugi", "status": 0 }
]
```

::note
The frontend accepts either a top-level array **or** an object of the shape `{ "data": [...] }`. Providers with `status !== 1` are filtered out client-side and never shown, so it is safe to include disabled providers in the response.
::

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| (array item) `id` | `number` | Used as `provider_id` filter on [Games](/api-reference/casino/games) and [Popular Games](/api-reference/casino/popular-games), and sent in the [Launch Game](/api-reference/casino/launch-game) payload. |
| (array item) `status` | `0 \| 1` | `0` hides the provider from the filter panel entirely. |

### Tenant-scoping notes for backend

- The provider list (and which are enabled) is tenant-specific integration configuration.
