## `GET /{tenantId}/{country}/popular`

Returns a paginated list of popular casino games, filterable by category and provider, used to render a "Popular Games" rail separate from the main catalogue.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `en` | Locale code. |
| `page` | `number` | `1` | 1-indexed page number. |
| `per_page` | `number` | `20` | Page size. |
| `category_id` | `number` | — | Filter by category id. |
| `provider_id` | `number` | — | Filter by provider id. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/popular" \
  --data-urlencode "lang=en" \
  --data-urlencode "page=1" \
  --data-urlencode "per_page=20"
```

### Tenant-scoping notes for backend

- "Popularity" ranking should be computed from **the tenant's own** play data, not a shared/global ranking across tenants.
