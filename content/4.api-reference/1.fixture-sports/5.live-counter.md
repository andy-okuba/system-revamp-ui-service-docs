## `GET /{tenantId}/{country}/live/counter`

Returns the total number of currently live games, broken down per sport. Used to render the "Live" badge/count in navigation and sport tabs. The frontend treats network failures as a soft error (returns `{ total: 0, sports: [] }` and only logs a warning).

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/live/counter" \
  -H "Accept: application/json"
```

### Sample response

```json
{
  "total": 37,
  "sports": [
    { "sport_id": 1, "sport_name": "Football", "games": 22 },
    { "sport_id": 2, "sport_name": "Basketball", "games": 9 },
    { "sport_id": 5, "sport_name": "Tennis", "games": 6 }
  ]
}
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `total` | `number` | Total live games across all sports for the tenant. |
| `sports` | `Array<{ sport_id, sport_name, games }>` | `games` is the count of live games for that specific sport. |

### Tenant-scoping notes for backend

- Counts must only include fixtures/markets that are **live and offered** to the requesting tenant (e.g. exclude sports the tenant has disabled).
