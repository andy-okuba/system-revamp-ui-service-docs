## `GET /{tenantId}/{country}/tournaments/{sportId}`

Returns the list of tournaments/leagues available for a sport, used to populate the tournament/league filter dropdown.

Consumed by `fetchLeagues` in `stores/fixtureStore.ts`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `sportId` | `number` | Yes | Sport identifier (defaults to `1` client-side if not supplied). |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/tournaments/1" \
  -H "Accept: application/json"
```

### Sample response

```json
[
  { "tournament_id": 17, "name": "Premier League" },
  { "tournament_id": 8, "name": "La Liga" },
  { "tournament_id": 35, "name": "UEFA Champions League" }
]
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| (array item) `tournament_id` | `number` | Matches `tournament_id` filter used on the Highlights endpoint. |
| (array item) `name` | `string` | Display name of the tournament/league. |

::note
Response must be a top-level JSON **array**. Any non-array response is treated as an empty list by the frontend.
::

### Tenant-scoping notes for backend

- Only return tournaments containing fixtures the tenant actually offers; tournament IDs used in filters must resolve consistently for that same tenant on the Highlights endpoint.
