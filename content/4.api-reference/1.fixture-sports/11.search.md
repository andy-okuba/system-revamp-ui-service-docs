## `GET /{tenantId}/{country}/search/{sportId}`

Free-text search across fixtures (team names, tournament, country) for a sport, with the same pagination shape as the Highlights endpoint. Used by the global search modal.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `sportId` | `number` | Yes | Sport identifier (defaults to `1` client-side if not supplied). |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `page` | `number` | current page | 1-indexed page number, resets to `1` on a new query. |
| `per_page` | `number` | `20` | Page size. |
| `highlight_market_id` | `number` | `0` | Reserved filter, currently always sent as `0`. |
| `search` | `string` | — | Required. Minimum 2 characters; the frontend does not call this endpoint for shorter queries. |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl -G "https://api.touchvasgaming.com/1001/ke/search/1" \
  --data-urlencode "page=1" \
  --data-urlencode "per_page=20" \
  --data-urlencode "highlight_market_id=0" \
  --data-urlencode "search=arsenal" \
  -H "Accept: application/json"
```

### Response field reference

Same envelope as [Highlights](/api-reference/fixture-sports/highlights): `total`, `remaining_records`, `last_page`, `from`, `to`, `data[]`. Each `data[]` item shares the same fixture shape as the Highlights endpoint (`highlight_market.outcomes`, `fixture_status`, etc.).

::warning
As with Highlights, an empty or non-array `data` stops pagination client-side — always return `"data": []` when there are no more matches.
::

### Tenant-scoping notes for backend

- Search results must only include fixtures/odds belonging to the requesting tenant.
