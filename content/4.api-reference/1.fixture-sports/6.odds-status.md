## `POST /{tenantId}/{country}/odd/status`

Re-validates the current status and price of one or more bet-slip picks immediately before bet placement, so the UI can flag odds changes or suspended selections. Requires an authenticated user.

Consumed by `checkOddsStatus` in `stores/fixtureStore.ts`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |

### Headers

| Header | Value | Required |
| --- | --- | --- |
| `Accept` | `application/json` | Yes |
| `Content-Type` | `application/json` | Yes |
| `api-key` | User's auth token (bearer-style, sent as raw value) | Yes |

### Request body

```json
{
  "odds": [
    {
      "market_id": 1,
      "match_id": 60417210,
      "outcome_id": "1",
      "producer_id": 1,
      "specifier": ""
    },
    {
      "market_id": 259,
      "match_id": 60417210,
      "outcome_id": "1714",
      "producer_id": 1,
      "specifier": "hcp=1:0"
    }
  ]
}
```

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `odds` | `Array<Pick>` | Yes | One entry per bet-slip selection. |
| `odds[].market_id` | `number` | Yes | Market id of the pick. |
| `odds[].match_id` | `number` | Yes | Match id of the pick. |
| `odds[].outcome_id` | `string` | Yes | Outcome id, always sent as a **string**. |
| `odds[].producer_id` | `number` | Yes | Feed producer id (e.g. `1` = pre-match, `3` = live). |
| `odds[].specifier` | `string` | No | Empty string `""` when not applicable (e.g. non-handicap markets). |

### Current contract (as implemented today)

::warning
The existing client type for this response is untyped (`any[]`). The section below is the **recommended explicit contract** the backend should implement so the frontend can safely bind types and remove the `any[]` fallback.
::

### Recommended sample response

```json
[
  {
    "match_id": 60417210,
    "market_id": 1,
    "outcome_id": "1",
    "specifier": "",
    "producer_id": 1,
    "active": true,
    "status": "active",
    "odds": 2.10,
    "odds_changed": false
  },
  {
    "match_id": 60417210,
    "market_id": 259,
    "outcome_id": "1714",
    "specifier": "hcp=1:0",
    "producer_id": 1,
    "active": false,
    "status": "suspended",
    "odds": 1.85,
    "odds_changed": false
  }
]
```

### Recommended response field reference

| Field | Type | Notes |
| --- | --- | --- |
| `match_id`, `market_id`, `outcome_id`, `specifier`, `producer_id` | echoed from request | Allows the frontend to match each result back to its bet-slip pick. |
| `active` | `boolean` | `false` means the outcome must be removed/disabled in the bet slip. |
| `status` | `"active" \| "suspended" \| "removed"` | Human-readable status for UI messaging. |
| `odds` | `number` | Current live price for the outcome. |
| `odds_changed` | `boolean` | `true` when `odds` differs from the price the user had in their slip; frontend should prompt the user to accept the new price. |

### Tenant-scoping notes for backend

- `api-key` identifies the user; the tenant context still comes from the path — validate that the authenticated user belongs to the given `tenantId` and reject cross-tenant odds checks with `403 Forbidden`.
- Odds/prices returned must reflect the tenant's own margin configuration, not a shared global price.
