## `GET /{tenantId}/{country}/highlight/market/alias/{sportId}`

Returns the list of highlight markets (with display aliases) available for a sport, used to populate the market filter dropdown on listing pages.

Consumed by `fetchMarkets` in `stores/fixtureStore.ts`.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke`. |
| `sportId` | `number` | Yes | Sport identifier (defaults to `1` client-side if not supplied). |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/highlight/market/alias/1" \
  -H "Accept: application/json"
```

### Sample response

```json
[
  { "market_id": 1, "market_name": "1X2" },
  { "market_id": 18, "market_name": "Over/Under" },
  { "market_id": 60, "market_name": "Both Teams to Score" },
  { "market_id": 259, "market_name": "Handicap" }
]
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| (array item) `market_id` | `number` | Matches `highlight_market_id` filter used on the Highlights endpoint. |
| (array item) `market_name` | `string` | Display alias shown in the market filter UI. |

::note
Response must be a top-level JSON **array**. Any non-array response is treated as an empty list by the frontend.
::

### Tenant-scoping notes for backend

- Only return markets the tenant has enabled for highlight display; market aliases/naming may also be tenant-specific (white-label wording).
