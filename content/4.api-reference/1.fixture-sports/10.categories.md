## `GET /{tenantId}/{country}/categories/{sportId}`

Returns the list of categories (typically representing countries/regions a competition belongs to) for a sport, used to populate the category/country filter dropdown.

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenantId` | `number` | Yes | Tenant/operator identifier. |
| `country` | `string` | Yes | Country code, e.g. `ke` (routing context — distinct from the categories returned in the response body). |
| `sportId` | `number` | Yes | Sport identifier (defaults to `1` client-side if not supplied). |

### Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

### Sample request

```bash
curl "https://api.touchvasgaming.com/1001/ke/categories/1" \
  -H "Accept: application/json"
```

### Sample response

```json
[
  { "category_id": 302, "country_code": "ENG" },
  { "category_id": 108, "country_code": "ESP" },
  { "category_id": 45, "country_code": "EUR" }
]
```

### Response field reference

| Field | Type | Notes |
| --- | --- | --- |
| (array item) `category_id` | `number` | Matches `category_id` filter used on the Highlights endpoint. |
| (array item) `country_code` | `string` | Short code representing the competition's country/region (e.g. `ENG`, `EUR` for continental competitions). |

::note
Response must be a top-level JSON **array**. Any non-array response is treated as an empty list by the frontend.
::

### Tenant-scoping notes for backend

- Only return categories that contain fixtures the tenant actually offers for the given sport.
